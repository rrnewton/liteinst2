# Selected hidden/stripped C qualification

This recipe qualifies explicit trusted-range selection of the existing nonempty
C checksum leaf. It does not discover function boundaries in an arbitrary ELF.
The unsafe loader premise comes from independently retained compiler metadata
and the complete trusted final file. No performance or accuracy claim follows.

Run at a clean committed revision, with fresh absolute `$RAW` under `ignored`:

```sh
$PYTHON -B tools/rapid-profiler/verify_selected_interval.py \
  --revision "$REVISION" --raw "$RAW" --toolchain "$TOOLCHAIN" \
  --user-home "$USER_HOME" --cargo-home "$CARGO_HOME"
```

The runner first requires six provenance and eight transcript-control methods,
then executes the unchanged default ordinary verifier: four state pairs, the
short-RET refusal and eight original/eight installed calls. It also requires
all 24 ordinary/Tree admission methods, four selected-state validators and
seven selected-consumer validators in exact release artifacts. Bounded libtest
listings authenticate the filtered count; every named required method must run
once with no failures or ignored cases. No optional performance route is used.

The unchanged C source uses the old CFLAGS plus `localize.map`. A bounded readelf
query records the selected LOCAL FUNC extent before stripping. The parser joins
that metadata directly to ELF bytes and requires unchanged selected code, all
executable LOAD bytes and LOAD/DYNAMIC/RELRO/STACK geometry after strip-all.
FINAL must lack the selected dynamic symbol, static symbols and debug sections.
A complete authority manifest binds both files, source/tools/commands and closed
receipts before distinct-inode candidate copies are created. One negative copy
changes exactly one selected byte; no live loaded owner is mutated.

The new native sequence is fixed: three public-loader preloading refusals, four
original/installed full-state pairs, then one eight-original/eight-installed
accounting population. Installed outcomes are sampled4/FunctionClosed3/Removed1,
with two Reports of two records, 16 events and four history actions. All 512
journal words, Report fields, actual worker return/join and the complete admitted
RET set are producer checks; compact CSV does not expose those full objects.
The wrong-file refusal is not a native wrong-object-base experiment.

State pairs keep the original 15-second absolute pair deadline and continuous
20,000-step limit. State wrappers use CPU90s/wall90s/1MiB. Functional/refusal,
fixture tools and Rust controls use CPU20s/wall30s/1MiB; Python controls use
CPU10s/wall15s/1MiB. Release builds use CPU120s/wall180s/128MiB. Each unchanged
bounded helper has its original wall+25 outer owner. The nested ordinary runner
has a separate 600-second/8MiB outer owner; all four internal bounds are unchanged.

`result.json` retains normalized commands, exact revision/tool/artifact/source
pins, compact rows, closure digests and failure/UNRUN distinctions. Private
before/after source maps, request/receipt/parent closures and raw streams remain
under `$RAW`. Prior failures stay separate failed attempts; this recipe neither
reclassifies nor retries them. Raw callback ticks are uncalibrated. An existing
recipe or a successful synthetic control is not a native qualification result.
