  --raw "$REPO/ignored/NEW_CORE_RUN" --toolchain "$TOOLCHAIN" --cargo-home "$CARGO_HOME"

The core command retains its separate eight-pair/148-comparison/two-malformed-child cohort. Its complete calibration target now requires 35 tests: the original 31 plus four controls of the actual optional frontend gate bytes, frame checkpoints, observer order and readiness mapping. None of those controls executes application code. The second native command retains all 27 existing stages and appends three, using the existing release artifacts and independently copied trusted/candidate C ELF. Cargo caches are permitted and reported; opt3/debug0/assertions/overflow remain required.

`optional-fast-state` and `optional-slow-state` each run two fixed seeds × lengths 1/64: eight pairs, sixteen executor children total. Only each candidate owns a controller helper (eight joins). The parent stops the actual executor at the first restored original instruction and asks that helper to arm after Fast selection or remove after Slow admission. The choice must survive the transition through the genuine RET. Complete inherited GPR/flags/XSAVE/data and `[S-128,stack_end)` comparisons span actual gate entry through post-POP. The child's real outer RET then executes after restoration of its own saved harness context, preserving actual RAX and the untouched return word. Setup and the rest of the stack are outside the state comparison. A single 15-second deadline begins before pair mappings/pipes/forks and ends after both normal reaps; each traced executor retains one continuous 20,000-step allowance. Each four-pair command has 90 CPU / 90 wall seconds and 1 MiB output.

The exact ignored `optional_native_reuse_and_old_owner` test is a separate functional/accounting case: 96 original calls on the eventual attached thread, then 96 real installed returns (32 Fast, 64 sampled Slow). It retains old A through B rearm, fills and reuses both observation buffers, validates three nonempty batches/all 128 events, two pre-call capacity refusals, three empty drains and complete A1/B63 Report joins. One helper really joins; model readiness never replaces physical return. This child retains 10 CPU / 15 wall seconds / 1 MiB and the existing bounded failure cleanup.

The recipe's strict helper requires exit0, unchanged inputs, ECHILD, empty diagnostics and zero descendant rescues. It preserves exact revision/source/tool/artifact hashes before and after each stage. Raw addresses and streams remain private; the two four-row state CSVs and one functional row are compact projections. Complete frame/journal/Report assertions are source-attested where those bytes are not exported. Comparison totals are taken from completed traces, not assigned in advance. These cases do not jointly prove full-state correctness for the 96-call schedule, qualify the independent backoff driver, establish timing accuracy or throughput, or measure a cheaper off path.
