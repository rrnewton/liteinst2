# Input-driven two-function profiling

`ordinary-interval normal-module-session CANDIDATE TRUSTED_FINAL CSV_VA CSV_LENGTH LENGTH_VA LENGTH_LENGTH K EPOCHS` profiles actual ordinary application calls to two independently selected leaves from one ELF source page. Numeric arguments are canonical unsigned decimal. CSV is first in ELF order and uses certified blocks (5–256 bytes); the bounded length leaf uses the unchanged whole-function profile (5–80 bytes). The trusted final ELF must be independent of the candidate. `K` is 10 or 1000 per function; `EPOCHS` is 1–520.

stdin contains at most 2048 LF-terminated records, each with at most 64 printable ASCII payload bytes. A field is unquoted text without comma/quote, or quoted text with doubled quotes; only comma or end may follow a closing quote. Spaces are literal. CR, NUL, control/non-ASCII bytes, embedded newlines and missing final LF refuse. An empty file has zero records; a bare LF is one empty field. Any extra byte after record 2048 refuses. These are product bounds, not a claim to parse every CSV dialect.

Every accepted record makes two real calls, CSV then bounded length, with independently derived expected results. A separate fixed accepted-byte snapshot and length are retained; only the guarded call buffer is passed to the target. Complete byte equality is checked before calls, before checkpoint and in final ledger checks. There are no hidden original calls or warmups. The existing private CALL/store helper is reused. Its emitted call/continuation must be independently inspected; source and copied metadata alone are not native full-state proof. A checkpoint follows four physical calls, an idle two-call returned record, or stop. Production batches therefore contain two or four calls. Calls within one record may belong to different generations. Both sampled and FunctionClosed/initial/removed observations remain present.

The existing Single session controller loop, worker transport, Schedule and epoch-slot transaction are shared through private fixed adapters. Three banks and bounded outer ledgers are allocated before Ready/start. Report record copies, history transfers, request storage and native validation retain real runtime costs. Raw journals are checked in all 512 words and retained privately; function IDs, original absolute history, global invocation slots/completed sequences and function-local retained ranks are joined to every Report payload. ReportCopied keeps its generation/token and one output obligation through repeated SharedOwner refusals.

The schedule remains exactly 10 ms with 2 ms lateness and the original 2 s shutdown limit, including final output completion. DONE.eof records an actual zero-byte read: an unterminated final record has eof=1 but input_complete=0. EOF requests stop. A typed input refusal stops acceptance and drains the accepted prefix; it stays nonzero. Scheduled stop without observed EOF is `INPUT_INCOMPLETE`, also nonzero. Genuine I/O, clock, SDK, source, worker or output failures fail-stop with retained owners and partial output. Printed DONE is tentative until the post-output Schedule check and real process closure. No retry, catch-up, deadline renewal or fabricated detach is performed.

Only after output drains and that final Schedule check succeeds, typed refusal exits 1 with exactly `normal-module-session INPUT_REFUSED: REASON\n` on stderr (REASON is syntax, overlong, unterminated or record_limit), and incomplete input exits 1 with exactly `normal-module-session INPUT_INCOMPLETE\n`. Successful completion has empty stderr and exits 0. Hard failures retain the existing FAILED diagnostic, trace and retirement details; a printed DONE does not override them. The bounded typed diagnostic is emitted after Schedule acceptance and is not an additional timed-output observation.

stdout uses the closed `module-session-v1` numeric wire: READY/RET, ordered CALL and RESULT, complete HISTORY/REPORT, SAMPLE, two COVERAGE rows, IO and DONE. SAMPLE order follows retained Report copy/output order, then invocation order inside each Report; it does not impose clock or generation sorting. All raw clocks, including zero/backward/mismatched AUX, are retained with the existing unavailable meanings. The maximum is 11,294 rows of at most350 bytes, or3,952,900 bytes, below4MiB. Input checksums are diagnostic; exact accepted bytes and guarded result owners remain retained. Coverage explicitly records unexercised RET roles.

This is a functional SDK/application capability. It does not establish timing accuracy, pure profiler overhead, cheap-off hooks after K, full A5, browser coverage, or arbitrary CSV/function admission. Original Single/T2/finite Module APIs, protocols, tests, whole-function bounds and native comparators are unchanged. All source-authored controls require independent compilation and execution. Streaming full-state and deterministic pending-owner native controls are separate required qualifications.
