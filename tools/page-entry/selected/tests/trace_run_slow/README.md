```

Every fresh source, full plan, complete W^X publication, inspected generated bytes, real release and cache prefix is retained. The genuine predecessor then supplies a new positive two-MOV plan. The actual proof is consumed, its fresh source is actually released, and `li2_tf_chain_run_released` checks the unchanged full TRACE frame. No generated slot is entered.
