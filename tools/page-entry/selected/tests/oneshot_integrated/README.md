Run `python3 evaluation/inprocess/page_selected_oneshot.py --expect-revision <full commit>` on one reserved CPU from a clean checkout. The evaluator builds the locked release decoder and opt-in one-shot bridge. It retains compiler include lists, source and tool identities, partial outputs, command captures, and final integrity checks privately. The public JSON contains numeric outcomes and reproduction hashes. No private candidate directory is required.

The dynamically linked fixture begins with RDTSC on a full page after its ELF metadata. Six owners publish and restore two RDTSC and four SYSCALL sites. A real write syscall reads its own original five instruction bytes; another reads the original entry RDTSC bytes. The program checks every returning source window, including its dormant continuation at PC+2, before exit. Completion requires six restorations and started effects, five returned and completed effects, and an exit owner still in RESTORED phase 7.

Two actual native helper-page admissions seed and inspect all sixteen GPRs, full flags including DF, and six selectors around the second RDTSC. All fourteen nondestination GPRs, including the actual RSP, must remain equal. RAX and RDX must zero-extend after both clocks. The four observed clock words may differ between native and gated output; every other byte of the 338-byte output must match and satisfy independent expected values. This output fixture is not an independent full kernel-FP/XSAVE oracle or a performance benchmark.

Application limits are 30 CPU seconds, 60 wall seconds, 512 MiB of address space, and 16 MiB per file. Nonzero exits, missing reports or restorations, source changes, and incomplete cleanup remain failures. The existing native-pages comparator still requires zero source patches in its separate profile. This one-shot profile supports same-page five-byte windows in the initial main image and at most eight owners. It does not establish arbitrary alternate entries, interpreter patching, concurrency, or complete B2/B3 coverage.
