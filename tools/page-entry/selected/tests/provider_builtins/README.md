# Configured clocks and syscall effects

This fixture qualifies the finite `deterministic-builtins-v1` policy through real NX ingress and separately through a restored one-shot UD2 landing. An actual linked interpreter begins with RDTSC or RDTSCP; main begins with RDTSC. Neither first instruction has a setup predecessor. Later operations seed all 16 GPRs, full flags including DF, all 32 ZMM registers and eight opmasks. The original frame, effect frame and committed frame are retained separately; a UD2 frame is never described as NX.

Each positive program contains six clock effects and ten syscalls. Configured clocks use the exact ordinal value and RDTSCP AUX. Four getpid/gettid calls use literal tagged results; five other calls return from the native dispatcher, and exit is a nonreturning native prefix. The eight main publication owners restore all original bytes, seven effects return, and exit remains RESTORED with effect-started set. A separate native-policy run checks the old native route with its actual clock observations. Native and gated stdout must equal all 42 literal bytes, including the original syscall and RDTSC source windows; clock values are not stdout and are not equated across executions.

Twelve additional processes reach one named invalid callback result/status, actual callback UD2, or genuine forbidden native prctl. Every bad operation remains failed with exit 125. The reader checks its exact entered/returned/committed prefix, retains existing syscall preclobbers, and requires no later row or effect. An invalid callback never silently retries native execution. Fault labels are authenticated against the actual bridge ELF.

The complete record is below the unchanged 16 MiB limit. It retains every byte of each initialized kernel FP/XSAVE extent and zero unused capacity, complete ucontext buffers, both 8 KiB source domains, both 16 KiB data/stack domains, all eight owner prefixes, and an explicitly bounded 256-byte window around the actual initial interpreter RSP. The startup window is not a claim about the entire initial stack mapping. Initial application data is checked against the emitted ELF; each effect must preserve both complete data domains. Live post-sigreturn GPR/flags/selectors/vector/mask captures join the next authentic NX frame. Unused sample and nested-event storage must remain zero.

The observer uses exact reversible source insertions and fixture-only immutable callback bindings. Production validators, gates and default builds remain unchanged. The builtin completion helper preserves the complete existing generic/cache/chain/rseq predicates, with one explicit accounting extension: selected syscalls equal native forwards plus the independently proven four replacements. No native-forward counter is rewritten. The default profile still uses its original validator.

The enclosing evaluator must bind the actual release recipe, compiler headers/tools/archive, linked fixture and bridge ELF, actual file-only DWARF layout, namespace, captures, process outcomes and final source/artifact custody. Original provider385, callback51, four configured carrier pairs, same-revision six-owner positive, full49 negative, full17 rseq and registered fallback pair remain mandatory. These builtin programs deliberately have no rseq registration; they do not qualify registered builtin replacement. Execution results are reported separately. This fixture does not establish full B2 completion or performance.
