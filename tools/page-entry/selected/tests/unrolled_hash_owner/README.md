This reader consumes the complete actual FD3 owner record from the distinct
unrolled application qualification profile. It does not execute a decoder or
infer successful execution from a process exit. The file-only GDB extractor
binds the emitted wire and anonymous owner by their actual types, inventories
every transitive private structure, and records the compiler's FP-member
alignment witness. The reader independently checks source field order, size,
alignment, embedded edges, padding, complete array capacity and record footer.

`read(record, layout, image, app, pid, cpu, exit_status, control=0)` returns
observations and a numeric summary. The qualifier supplies authenticated original
ELF bytes and sealed carrier extents in `image['objects']`, indexed by actual
lifecycle object IDs. Dependency backing facts contain `launch_fd`, `dev`,
`ino`, `size`, and `seals`; retained lifecycle duplicates are separately observed
FDs. `main_object` and `interpreter_object` identify the source-defined registration
order. `uid` is the actual launch UID, joined to the private sink's recorded UID
and the nested signal's sender UID. Mapped source biases are derived from actual
page/file-offset observations and retained ELF load ranges, not from namespace
preparation. The caller also authenticates every input and final artifact.

Every used slot and generated page is checked, including fill, all 65 branch
displacements, actual decoded rows, original-source generation identity,
publication/open/close receipts and both protected arena observations. Focal
rows retain complete source, data and stack bytes; actual before/redirected
frames differ only in saved RIP. Actual complete FP buffers remain mandatory.
The independent application reader compares full native/gated architectural
states, including actual AF; this reader does not manufacture AF. Nested FP is
instead the complete initialized-handler model, with same-process CPUID geometry
and the separately observed live handler PKRU. Raw SI/UC bytes are retained;
unspecified kernel padding is not claimed to have an independent value model.

`terminal(parsed, unrolled, owner)` joins complete pair and rseq rows, physical
native counters, the distinct global native-close snapshot, current route,
cleanup and retained fetch prefix. The caller still runs every unchanged old
report schema and completion/failure gate. Global loader entries are not counted
as focal application entries; their retained source/slot/owner contract is
checked without claiming a separate native data-result oracle for each loader
loop. The seven supplied controls remain exit 125 failures, including failed
close/sync prefixes and occupied fetches. The native mode-0 reference separately
checks their actual entry state and any reached architectural endpoint.

`controls(...)` applies fixed byte corruptions only to copies of an already
accepted record: 28 for each ordinary mode and controls 3/7, 32 for control 1,
27 for controls 2/4/5, and 20 for control 6, totaling 441 supplied refusals across the 16 gated
subjects. These are reader controls, not additional native operations. All 25
actual application/control subjects and their original resource bounds remain
the qualifier's responsibility. Qualification requires independent review and fresh observations.
