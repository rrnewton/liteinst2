Private custody observation leaf
===============================

This leaf observes the reviewed `LI2_TF_SEALED_CUSTODY=1` runtime. It adds no
execution authority, recipe, cohort runner or passing result. Keep all old
profile observers and readers unchanged. The separate new reader must accept
the actual custody schema explicitly; origin maps are never current maps.

`prepare(root, out, pin, *, stack=False, fault_event=0, overlap=False)` creates
one bounded source view. Every product change has a complete inverse to the
authenticated input. It preserves the eight non-fetch adapters and both
appendages from the old lease preparation. Three old inner fetch adapters are
replaced by outer stage/commit return wrappers and the two literal pre-ref
publication seams. Original callback bodies are not runtime-policy edits.

The generated old observer gets one storage substitution: its `lso_record`
becomes the first subobject of the actual named `cso_stream`. Its function
bodies and first write sequence remain unchanged. **Binary layout identity
with an old profile is not claimed:** the custody macro expands nested runtime
types. The new compiler's static assertions and complete emitted DWARF must
prove every size, offset, field, padding byte and the unchanged 16 MiB cap.

Each of twelve fixed rows corresponds exactly to the old observer event index.
`entry` and `returned` accompany the base event's genuine full before/after
frames, owner, fetch and rseq objects. `stage` and `commit` are copied only after
the actual outer API returns; they retain the full owner, complete actual
partial singleton fetch, rseq, session, custody/maps counters and RX view.
Their `argument_ref` is the pre-call ref, including when commit's input/output
alias; `published_ref` is copied only from an actually successful commit.
The snapshot's `fetch.ref` is the actual ref at the snapshot, which can differ
from the singleton progress in the deliberate pre-ref failure prefix.

`handler_before` is observed before the real `li2_tf_chain_handler_end` call.
`ready` and `ready_frame` are copied after it returns and before the unchanged
global maps phase end. The name does not assert a READY phase: fallback/miss
paths retain their actual EMPTY or other state. No returned TRACE frame is
labelled as handler-end evidence. Session bytes are copied from the actual
owner's session pointer; a NULL pointer leaves literal zero bytes. The chain's
separate session address is also retained. Partial-view copying performs no
validator, query or permission operation.

Source-selected configurations are exactly ordinary `(0,0,0)`, warm faults
`(0,1,0)`, stack `(1,0,0)` or warm overlap `(0,0,1)` in the order
`stack,fault_event,overlap`. Their literal generated headers and compiler-M
closure must be authenticated by the future qualifier. Cases6–9 retain their
old ELF bytes and real failure operations; warm variants inject at event1
after the preceding transfer. They do not use the old reader's one-event
failure model. The overlap fixture is a separate source dependency, not
implemented or qualified by this leaf.

Stage injection is after the outer return and seed snapshot. Commit injection
is after the real singleton replacement and before ref publication, on both
the fresh and retained paths. The full `fault` snapshot precedes the supplied
stale-ref mutation, real backing close or real nested signal. Existing failure
status, cleanup owner and revocation observations remain visible. A stale
authentication failure is not verified close or release.

Stack mode retains old endpoints BODY+32/GUARD and adds the genuine second
pair BODY+96/GUARD+128. Both extra rows retain complete before/after rn_frame
payloads. The separately authored stack proof belongs to stdout, not this
record. No stack-growth, new-subject or performance result is supplied here.

The terminal snapshot precedes the old cleanup-map observation and writes.
The old complete base record is written first, then the complete appendage.
Any partial write is rejected by the future exact-length reader. The stream
has no inter-object gap or trailing bytes by compiler assertion. The private
source/ABI forecast is 16,582,848 bytes, including both extra stack endpoints;
it is not a substitute for actual emitted layout or full saved-data replay.
