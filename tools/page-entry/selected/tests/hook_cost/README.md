This additive evaluator measures the optimized C NX callback path over the five
existing B2 reference trajectories. It first runs the unchanged fresh format
probe, raw/model/explicit-trap producer and complete five-case C comparison.
It then builds five timing bridges and requires each exact ELF to pass the
unchanged full-state reader in `qualify` mode before using `measure` mode.
No production file, recipe, refusal or architectural comparator is replaced.

After committing the sources, reserve one CPU and run:

```sh
python3 evaluation/inprocess/page_selected_hook_cost.py --expect-revision FULL_COMMIT
```

The existing `Build`, supervised invocation and source/tool/header/archive/ELF,
namespace, capture and finalization checks remain in use. The C cases and links
retain 30 CPU seconds, 60 wall seconds, 512 MiB and 16 MiB limits. The fresh
reference producer retains its own original bounds. There is no second Cargo
cache. Actual compiler commands and emitted timer, boundary and handler bodies
are retained privately; the public JSON contains their custody hashes, revision,
hardware, outcomes and numeric measurements without host paths or raw logs.

For each fixture, three warmup children precede ten measurement children. These
65 invocations are fixed, with no retry or outlier removal: 51 warmup and 170
measured callbacks. The measured class counts are CPUID20, RDRAND20, RDSEED40,
RDPID30, RDTSC40, RDTSCP10 and SYSCALL10. Class summaries combine distinct sites;
the public sample and row columns also retain each fixture/ordinal separately.

The private timer uses raw `clock_gettime(CLOCK_MONOTONIC_RAW)` through the
existing trusted syscall site, while TSC permission stays unchanged. It adds no
application clock API. Each process retains 64 adjacent-read calibration pairs;
no overhead is subtracted and zero deltas remain observations. This profile has
no registered timing observer: each raw clock syscall invalidates map-phase
reuse on entry and return. Measured handler/cycle intervals include that
clock-induced map-reuse invalidation; they do not estimate uninstrumented runtime.
Each selected
row records five timestamps: outer-handler entry after its existing guard,
checked fixture callback entry/return, outer-handler tail after owner cleanup,
and the next genuine NX entry at the exact original successor PC. That next
event must pass the existing source preparation, decode and fault-range guards.
Adjacent selected effects share one entry timestamp. A matching PC on a TRACE
completion is not an NX entry and consumes no timing read. A genuine NX entry
sample is tentative until the selected ingress authenticates and consumes it in
the same handler; an unconsumed sample fails, including a native retry. A missing,
refused or different next event fails instead of supplying a duration.

The reported intervals are callback return minus callback entry, handler tail
minus entry, next NX entry minus tail, and next NX entry minus current entry.
The last interval is exactly the sum of handler service and return/refault.
They include timing instrumentation and the checked fixture policy. They are
not bare instruction latency, uninstrumented production cost, a named production
policy benchmark, one-shot publication cost, nonreturning exit latency, or
whole-program performance. No full B2/B3 completion follows from a finite pass.

The fixed timing record is 2,304 bytes: 32 header words, four 32-word rows and
64 two-word calibration pairs. Qualification retains the entire unchanged
1,258,752-byte record and 3,536-byte format trailer, then this timing record.
Measurement retains only timing plus the same format trailer (5,840 bytes).
The header retains actual native/fallback counters; every measurement must
match its same-ELF full-state qualification counters. Attempted, actual PID,
reaped terminal and accepted process counts stay distinct. A failed prefix
does not become a completed timing sample. Raw calibration remains private;
its count/range/hash and all sample endpoints fit the original 64 KiB public cap.

Source-only supplied-record controls are not emitted-code or native evidence.
The first actual bounded qualification must retain any compile, event, state,
format or timing failure as failed; no tolerance or expected outcome is relaxed.
