# Finite one-shot failure controls

Run the committed positive one-shot pair first, then supply its private receipt to the negative evaluator. Both runs must use the same exact clean revision and a single reserved CPU:

```sh
python3 -B evaluation/inprocess/page_selected_oneshot.py --expect-revision "$REVISION"
python3 -B evaluation/inprocess/page_selected_oneshot_failure.py --expect-revision "$REVISION" --positive-receipt "$POSITIVE_RECEIPT"
```

`POSITIVE_RECEIPT` is the first command's corresponding `target/evaluation/inprocess/<printed-stem>/receipt.json`. Its actual successful release archive, original ELF and native output are reused. This evaluator runs no Cargo command. It authenticates the positive source identity, both completed lanes, every retained command/capture/input/artifact and lexical alias, and replays the unchanged positive output and six-owner completion checks before building the C-only derivative. All17 derivative translation units have actual compiler include closure before compilation. Four owner-entry renames enable the test interposer; all other product translation units and the Rust archive remain unchanged.

The default cohort requires all49 modes:48 terminal target failures with zero selected-effect starts, returns or completions, plus mode47's refused first site and genuine completion through fallback/five later publications. The supplied callback and malformed-frame controls are labeled separately from genuine kernel `EINVAL`. Every process retains the30CPU-second,512MiB address-space,16MiB file and60wall-second bounds. C compilation retains60CPU/120wall with the same memory/file bounds. `--case N` is diagnostic and can only report `passed_subset`; it cannot qualify the full cohort.

The reader checks the entire retained source/data pages, genuine signal frames and full kernel FP extents, callback/raw-operation prefixes, first errors and cleanup state against actual ELF/DWARF extents. Overlapping physical signal-frame views use authenticated actual addresses and only the named supplied byte edit; all other bytes stay exact. Cleanup observations precede the outer lifecycle abort. A failed cleanup never earns verified restoration or continuation credit.

Public JSON retains normalized commands, actual exits, hashes, every attempted case's numeric result and explicit failures. Raw records, signal addresses, logs and namespace paths remain private. Historical V4 failures stay failed; a later successful run requires fresh records with actual `si_address` observations.

Scope is the finite same-page native negative fixture. There is no claim for nested delivery, interrupted individual byte stores, cross-page product windows, arbitrary application RAM, independent live FS/GS observations, performance, or B2 completion. No old positive predicate or resource bound is relaxed.
