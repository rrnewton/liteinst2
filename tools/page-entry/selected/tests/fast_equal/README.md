# Exact immutable-range equality primitive

Run `python3 -B evaluation/inprocess/page_selected_fast_equal.py --expect-revision <full-commit>` on one reserved CPU. The evaluator compiles the actual tracked `step_owner.c` twice at `-O2`: the default scalar helper and its opt-in `LI2_FAST_EQUAL` word-load branch. Both use the test-only `LI2_EQUAL_ORACLE` wrapper. It checks emitted object/final-ELF bytes, source/tool/system-header/alias closure, exact executable and record extents, and both functional lanes before measurements. No Rust archive or copied helper is used.

The unchanged oracle covers72 lengths,5,832 placements,17,496 equal calls,280,260 unequal calls,16 zero-length guard/null calls and28 overlaps. Full input images stay checked, including98,869,248 verified bytes; mappings surround the operands with inaccessible pages. The helper reads each complete8-byte chunk only while eight bytes remain, followed by the original byte tail. It accepts unaligned immutable ranges without reading a suffix. This is an ordinary C helper with DF clear, not a constant-time function or a replacement for application flag/state comparisons.

Six processes run in order: scalar functional, fast functional, scalar measured, fast measured, fast measured, scalar measured. Every process retains the5CPU-second,15wall-second,512MiB address-space and16MiB file bounds. Each measured process retains eight positive integer nanosecond intervals, each covering8,192 warmed helper calls over2,444 bytes. Public JSON includes all32 raw intervals, actual revision/hardware, four compilation command vectors, native command outcomes and exact private command/source/artifact digests. Raw captures remain private. A failure prevents measurement qualification and is retained.

`LI2_FAST_EQUAL` remains disabled in every runtime build recipe. The47 unchanged full-state owner/TRACE/register/control/REP processes with the option actually enabled are still required before any runtime enablement. Primitive timings alone give no real-program speedup or completion credit. No comparator, equality call, range check, slot reset, old refusal or resource bound is removed.
