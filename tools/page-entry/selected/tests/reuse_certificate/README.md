This is an eight-process publisher transaction component. It includes the actual
runtime_loader.c translation unit and links the other nineteen production units
and the retained scalar-feature decoder archive. No production body is copied or
stubbed. The CRT runs main; the build macro renames only unused loader _start,
leaving the actual raw gateway intact. Generated code is never executed.

The fixture creates a real sealed two-page ELF and maps its executable page
through the actual lifecycle. It holds the genuine15-byte fetch, obtains the
whole-page source ticket, and calls the actual planner, complete plan validator,
and cold per-head rseq/NONE proof. Session self-test/unrolled initialization,
zero-registration and caller/completion boundaries are explicitly supplied.
The component does not establish real kernel registration absence, a genuine
signal/session boundary, frame preservation, runtime completion, or a completion
permit produced by srr_quiesce. No signal handler is installed. These limitations
are recorded as component_only=1/supplied_boundary=1 and supplied_completion=1
only in modes1/2. The full43 owner qualification remains separately mandatory.

The new certificate functions and ordinary reuse claim/commit/abort functions
are actual compiled code. Source/generation/complete-payload checks, anonymous
mappings, protection, synchronization, physical maps acquisition, and decoder
statistics are actual. Mode2 supplies the surrounding retirement bookkeeping
and executes each actual certificate retirement transition in its required
order; it does not claim the full srr_prepare caller/frame gates ran. The four
terminal mappings and two descriptors close using raw terminal cleanup, after
actual source validation/release and byte equality. It never resumes application
code, and makes no claim that raw terminal unmap reconciles lifecycle bookkeeping.

retains its corrupted descriptive permit while certificate identity is false.
