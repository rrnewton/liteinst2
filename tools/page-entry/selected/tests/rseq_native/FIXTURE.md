# Finite registered-native qualification

The existing profile README defines the production envelope. These sixteen
fixed subjects add a real native reference and observed bridge pair; they do
not replace the original six-owner, 49-negative, 17-rseq or native-boundary
cohorts. Build/execute only after source review on the exact committed revision.

Each subject is the same high ET_EXEC in both lanes. Its unchanged emitted
custom interpreter begins with CPUID. Setup creates a genuine anonymous guarded
page, sets real FS/GS bases, registers the 32-byte area, and copies all 4096 bytes
with ordinary MOV loads/stores. The body and complete halos must pass the
unchanged native scanner. No instruction or byte-pattern exception is provided.

The native lane receives the literal argument `native`. Before registration it
installs a genuine SIGSEGV observer and removes X from the guarded continuation
or boundary page. The kernel's actual frame is copied before/after the observer;
successful references only restore X and return that unchanged frame. Distinct
abort, straddler and data-fault references remain failed operations. Wrong
signature, inaccessible descriptor and UD2 require their exact kernel-fatal
exit and empty output. A real BODY NX/native or successful BODY admission/gated
prefix is written while the publication word is still zero, before the fatal
operation. Their native reference observer uses SA_RESETHAND and, while the
word is still zero, queries the actual default SIGSEGV disposition before
returning. Native record version2 stores query-complete at h14 and the four
actual kernel action words at h15..18; other cases retain zeros there. It proves
actual pre-operation reachability; no terminal frame, unobserved cause or
verified close is invented. Case12's critical interval includes its publication
MOV and the original boundary fault, with the real signature/abort marker stub
outside that interval at TAIL+512. Registration deliberately uses the mismatched
signature; no scheduling gap can silently clear a published descriptor first.

The gated adapter copies actual handler arguments immediately after the pure
product preentry hook, before old generic/frame gates. It wraps the unchanged
native ingress return and actual instruction guard. The old implementation
bodies are recovered byte-for-byte by eight inverses. Unsafe preentry failure
cannot reach the observation hook and does not issue a reporting write.

The coincident case uses actual `48 89 | c3` split bytes. Its descriptor excludes
the next-page boundary from the critical interval; abort_ip equals that boundary
and the registered signature is the actual preceding `90 90 48 89`. This is an
adversarial kernel-accepted descriptor geometry, not a source-level claim about
a well-formed critical section. The resulting RET preserves the original RBX
and returns to a preseeded real stack target. Equality of RIP/si_addr/CR2 is not
used as evidence that no abort occurred.

The scheduling interval includes the publication MOV itself before the PAUSE
loop. A separate bounded process, controlled by the evaluator, must be ready on
the same reserved CPU. Only genuine scheduling can reach the retained abort
stub. No abort, timeout or incomplete output is a failed qualification, never a
skip. Both processes' identities and cleanup remain explicit.

The four selector cases execute actual MOV-to-FS/GS in the native body, then an
actual segmented store on the dirty continuation page. Fresh ARCH_GET_FS/GS
must supply base0 after loading selector0x2b. Overlap cases intentionally store
zero to an already-zero publication word: nonexecution is established by the
actual old guard returning1205, full typed Code282/RANGE8 and unchanged borrow,
route and TF-open observations, not by a zero memory difference.

Every pair has a genuine native full-FP reference; the three fatal cases compare only the safe pre-operation frame. Complete retained
UC/FP/source/data/rseq bytes are checked before/after real owner calls; body FP
images also remain exact across native execution. Cross-lane UC comparison
retains every byte after separately validating three signal-envelope identities
(altstack base/size and FP pointer). The supervisor still proves the initial empty mask. Native application setup then makes a real mask syscall to install the controlled profile’s exact application mask; complete mask/oldmask fields remain equal across lanes. Only mode and
actual kernel mm_cid distinguish the full data/page comparison. No invented
state is supplied to the product. Successful stdout includes the full 16 KiB
literal-checked data/stack image and 4 KiB rseq page, all 16 GPRs, flags/DF, six
selectors, 32 ZMM and 8 K captures. This is not a separate whole-live-XSAVE reader;
the complete kernel FP records are the cross-lane FP authority.

Helper API: `build.sh metadata.S output case_number`; `prepare(root,out,pin)`;
`check.elf(bytes,interpreter,case,native_policy)`; `check.native` and
`check.gated` receive record bytes, their own actual DWARF layout, image, PID and
actual exit. `check.pair` receives both records, both stdout payloads,
`{'native': native_layout, 'gated': bridge_layout}`, image, both actual PIDs and
the independently reserved sole CPU. Every observed rseq CPU must equal it.
The outer evaluator owns all tools, headers, namespace, emitted ELF, archive,
command/capture/final custody and exact exits. All failures remain retained.
