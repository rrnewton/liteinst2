# Scalar owner capture reader

These files qualify the separate diagnostic capture profile. They do not give
the normal runtime, a source snapshot, or a descriptive decoder execution
authority. The required application population is13 native+13 gated modes plus
14 mode0 gated controls. Every actual attempt and failure remains in its receipt.
The existing30CPU/60wall application limits and all native/full-state
comparisons remain mandatory. No execution has validated this source packet.

`layout.py` runs under the bounded metadata GDB invocation without an inferior.
It extracts the emitted `sro_wire` and anonymous `selected_scalar_region` types,
all transitive objects, actual member-alignment witnesses and SI/UC offsets.
`wire.py` compares the complete source-declared type graph and padding. It reuses
the unchanged old unrolled reader's generic layout and actual owner helpers;
that committed leaf is a mandatory input, not copied historical evidence.

`boundary_requests(data, layout)` extracts at most65 unique32-byte source
queries: one unsupported boundary for each of64 possible published slots and
the retained scratch boundary/halt. Extraction is not acceptance. The separately
compiled `boundary_probe.c`, linked with the same retained production
scalar-region decoder archive and unchanged `tests/decoder/support.c`, receives
exactly one immutable request-file argument. It runs under the original decoder
3CPU/10wall/256MiB/1MiB profile. Compiler-M, actual ELF/dependencies/archive and
whole request/output/command closures remain the evaluator's obligations.

Requests use a32-byte `<4Q>` header (magic0x315152534c49324c,version1,count,row32),
then `<QII16s>` rows (PC,available1..15,reserved0,whole zero-tailed window).
Responses use a128-byte header (magic0x315352534c49324c,version1,count,row344,
complete48-byte allocator snapshots before/after), then repeated request32,
API-status0/reserved0 eight bytes and full304-byte descriptor. Maximum extents
are2,112 and22,488 bytes. Invalid/truncated instructions are exact descriptor
statuses1/2 and refusals2/3; nonzero API status fails the metadata process. Every
query checks the entire unchanged allocator tuple after sealing.

`read(..., boundaries=response)` requires the exact request population and full
descriptor equality for every unsupported boundary or invalid/truncated halt.
Those rows never enter an executed graph. All accepted47-form instructions,
effects, reachability, cycles, exact-head edges, rel32 destinations, emitted
image, PC maps and the whole53,024-byte plan are reconstructed independently.
Failed scratch objects retain their exact first-failure partial image/map state
and receive no execution authority. There is no general x86 decoder claim.

The wire reader joins every published page to its actual immutable source key,
current borrow, generation, both protected arena geometries, physical maps
observations, full permissions/readback and original fetch/rseq/native-pair
prefixes. It retains full SI/UC and65,536 FP bytes, actual kernel64-signal masks,
TLS and typed GPR/flag conservation. Affected values and actual AF are compared
against native hardware by the separate application reader, not predicted here.

LIVE memory observations explicitly lack the8 or216 inaccessible stack bytes.
Typed READBACK requires the actual mapped load fault, published first error and
completed generated-page revocation before the single R-only restoration.
The complete224-byte stack and8,192-byte data readback must match the separately
authenticated pre-protection application/native observation. No fault resumes.

Controls1..14 keep their exact actual/supplied dispositions. The source-fixed
`CONTROL_COUNTS` has27 keys and2,219 supplied reader refusals. It retains every
old applicable capture corruption, coherent nested-mask/TLS/full-FP mutations,
and adds whole-plan, exact memory, mapped fault, second invocation and separate
boundary-observation corruptions. These controls have zero native-operation
credit. `terminal(parsed, scalar, unrolled, owner)` joins actual new and retained
old streams without rewriting status or confusing overlapping counters.

The qualifier must independently require all original terminal controls, all
native full-state pairs, actual cache-hit/generation evidence, and complete
source/artifact/command/descriptor cleanup. The guarded nested shim needs its
own actual emitted whole-body/gateway proof; prior compiled bytes are not proof
of this new capture artifact. Qualification requires independent review and
fresh observations.
