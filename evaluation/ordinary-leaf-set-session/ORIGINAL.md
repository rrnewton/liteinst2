The separate original reference calls each selected, uninstrumented LeafSet body on every accepted record. CSV fields includes the empty record's one field; length counts the encoded bytes; digits and spaces count their literal ASCII bytes, including bytes inside quoted CSV fields. Independent C and Python input/value checks precede acceptance. This is scalar and source-custody validation, not architectural-state, scheduling, performance or whole-worker qualification.

`original.c` includes the unchanged two-function reference under a renamed main. It retains that program's actual non-tail C CALL/store, strict framed-input parser, canonical integers, FNV and held-FD mount-domain/file/mapping checks. The old reference, six mount controls and all earlier recipes remain unchanged.

The new CLI is:

```
ORIGINAL ABS_DSO ABS_FRAME CPU N (FUNCTION_ID OP ELF_VA EXTENT POLICY RET_OFFSETS){N}
```

N is 1–4. Each table entry uses canonical decimal integers; OP is `csv_fields`, `length`, `ascii_digits` or `ascii_spaces`; POLICY is `certified` (extent 1–256) or `whole` (5–80). RET_OFFSETS is a comma-separated, sorted, unique list of 1–4 offsets. Entries must be disjoint and ordered by actual ELF VA. Their function IDs and operation identities are distinct. The bounded frame is exactly `MODCSV1\0`, a little-endian u32 record count, then a u8 length and exact payload for each record. It accepts at most min(2048,4096/N) records, 64 printable ASCII bytes per record, the inherited CSV grammar, and no trailing bytes. The catalog's malformed suffix is not part of the original leg.

Before invocation the parent must pin the original consumer, its unchanged included source, compiler and subtools, exact commands, complete DSO bytes and trusted copy, selected ELF FUNC/section/RX-load ranges, full decoded instruction/RET sets and the emitted C caller's complete FUNC/CALL/store/RET ABI. The caller shape is separately admitted from the installed Rust caller. The preserved module build uses `localize.map { local: *; };`: each selected function must have exactly one LOCAL FUNC definition in SHT_SYMTAB. GLOBAL or DYNSYM alternatives refuse. Labels or listed C3 bytes alone establish neither semantics nor complete decoding. The C program independently joins the supplied complete extents to ELF symbols, retains the DSO FD and full file bytes, and checks every byte of the exact one/two-page source union against its live RX mapping and held FD's mount identity before and after calls. It never fills gaps between nonadjacent pages. Code/file owners remain alive through normal exit; all failures stop without unwinding them.

Successful stdout is `LEAF_ORIGINAL_READY,leaf-original-v1,pid,tid,cpu,n,caller,records`, then one `LEAF_ORIGINAL_FUNCTION,index,function_id,operation,policy,elf_va,extent,entry,end,return_count` and its `LEAF_ORIGINAL_RET,index,offset` rows per selected function. These are declared RET offsets, not observations of return paths. Each accepted record yields `LEAF_ORIGINAL,record_id,length,fnv,value_0,...`, followed by `LEAF_ORIGINAL_DONE,records,calls,returns`. Calls and returns both equal N times records. The complete output has at most 2070 lines, each at most 350 bytes, comfortably below the unchanged 4 MiB cap. There is no epoch or elapsed-time field.

The recipe calls `original_output.frame(records, n=N)` and then `original_output.check(stdout, stderr, records=records, table=table, caller=caller, cpu=cpu)` on actual streams. Table keys match the LeafSet checker; caller keys are `extent` and `continuation`, converted from the independently admitted C shape. The checker retains every result, typed table/ready/totals and verbatim stdout. It requires empty stderr but cannot prove successful exec or normal closure. The parent separately requires actual exit 0, exact request/source/artifact hashes and complete normal owner closure. The eight inherited typed input refusals keep the old stderr prefix and actual exit 2; `refusal()` checks those bytes without promoting a setup failure.

The original 15-second cooperative deadline, 20 CPU-second/30-second external child bounds and output limits are unchanged. Every outcome remains retained, including refusal or incomplete closure; there is no retry or favorable selection.
