This run.py is byte-identical to the reviewed chain-r2 driver. It runs cold9 → native41 → real-program probe on one externally reserved CPU and retains all original joins, bounds and failure labels. SOURCE.json is a portable projection of every field consumed by that driver: script and installed_sources. The source facts bind the existing tracked stage implementation; no stage body is copied or changed. The chain remains failed if the program fails, even when its closed receipt is eligible for a later diagnostic profile. See ../README.md for the explicit command and input selection.
