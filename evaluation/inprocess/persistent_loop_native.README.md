After installing the reviewed source composition, reserve one CPU externally
and run at one clean exact revision:

```sh
python3 evaluation/inprocess/persistent_loop_native.py \
  --expect-revision FULL_40_HEX_REVISION --cpu RESERVED_CPU \
  --output target/evaluation/inprocess/tunables-native-attempt-1
```

The output must be a fresh direct child of `target/evaluation/inprocess`.
There are no retries. The fixed 82-command schedule contains 54 source/tool,
build, helper, DWARF and seed commands followed by all 28 lane0 subjects in
case-major order: cases0–6, each at placements0–3. Every expected exit remains
zero. Every subject retains the original 30 CPU seconds, 60 wall seconds,
512 MiB address space and 16 MiB output/file limit on the same reserved CPU.
Build, metadata, inspection, finite helper and seed bounds are the unchanged
`persistent_dynamic.BOUNDS` profiles. A failed but fully reaped/closed subject
may be followed by the next independent case; incomplete cleanup stops the
sequence. Failed outcomes and all completed command/capture artifacts remain
in the failed receipt.
