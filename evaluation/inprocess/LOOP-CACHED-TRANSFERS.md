# Cached transfers between admitted blocks

The experimental cached DIRECT profile joins already admitted members through
separately typed external E9 tails. It uses the shared DIRECT emitter and
decoder-free recovery. The ordinary legal-head lists remain authoritative;
auxiliary tails have distinct directory tags and complete source/owner identities.

The owner publishes immutable code, directory and proof data before entry.
Relevant RAW mapping or permission operations advance the corresponding epochs.
A stale completion can authorize only authenticated cold retirement, never a
warm entry. An auxiliary signal uses the actual saved PC and spill state for
recovery and then terminates the experiment.

Run the finite positive experiment from a clean revision on a reserved singleton:

```sh
python3.12 -B evaluation/inprocess/loop_cached_direct_context_native.py \
  --expect-revision <40-hex-revision> \
  --current-build target/evaluation/inprocess/<ro-build>/receipt.json \
  --current-build-sha256 <64-hex-receipt-digest> \
  --output target/evaluation/inprocess/<fresh-native-attempt>
```

The current RO build receipt supplies independently authenticated same-source
decoder compilation. Its real-program outcomes retain their original status.
The new collector requires all 43 commands, the 146-instruction native reference,
both complete gated application comparisons and every supplied observation
control. The observer records actual full frames and interior event counters.
Its extra queries and captures exclude performance credit.

The separate [component entry](loop_components/README.md) validates the shared
planner, auxiliary images, leases and recovery model. Actual invalidation and
recovery controls, the original arena/descriptor cohorts, full qualification and
whole-program performance remain required. This finite experiment does not
extend the existing native-page profile's private-memory isolation assumptions.
