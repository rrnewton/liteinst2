indirect two-argument call. A batch makes 2,048 calls with inputs `(i+1, 2*i+3)`
and requires checksum 6,296,576. Both generated images retain one real
`DataFlagSession`, managed control, callback and original PC. The early image
can bypass context capture; its enabled dispatcher retains the existing check.

Each process first executes two enabled controls and three complete disabled
qualifications. Each enabled control requires one saved-frame callback with
arguments `(7,11)`, return 18, an exact completed record, explicit disarm,
`Closed` admission and drainage. The retained point payload is the original PC,
not the argument pair. K completion alone is not physical disarm. Every later
row requires the flag false, unchanged diagnostics and retained reports, zero
callback/record/refusal increments, and unchanged source/generated bytes.

The timer contains only the identical indirect-call, argument and checksum

affinity checks, source checks and file output are outside. The child is its
single main thread; all setup is complete before timing. Qualification checks
every return; timed rows check the complete aggregate. The existing full-state

original development/test cohort and an additive matching-release cohort must

The fixed campaign has 12 independent processes, all six arm orders twice,
shuffled with seed 20261101. Each process retains 206 rows: five untimed,
nine warmup and 192 measured. Across twelve processes that is 2,472 rows; each
process makes 417,794 calls.
Three warmups and all 64 measured batches per arm are retained. Statistics use
12 process means and Student-t with 11 degrees of freedom; paired ratios use
log intervals. The primary ratio is early-disabled/ordinary-disabled. There
are no replacement runs, timing thresholds or outlier exclusions. An incomplete
or failed campaign receives no statistics.
