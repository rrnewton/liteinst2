It is an incomplete qualification component: the independent nested
`output.py`, exact-source native prerequisite, parent-only original reference
and final campaign are separate dependencies. It makes no native-state,
Schedule, timing, performance or full-A5 claim.

The future campaign freezes every plan and request before child 1. It uses the
unchanged Module corpus and `produce.case_spec`: 32 cases at K=10 and K=1000 in
each of five fixed qualifications. The 32 original references and eight
malformed-reference controls precede those 320 installed children. This
component runs only one supplied installed slot and has no retry operation.

Invoke the authenticated entry as:

```
python3 -B evaluation/ordinary-call-pair-session/produce.py \
  --plan ABSOLUTE_PLAN --plan-sha SHA256 --raw FRESH_IGNORED_DIRECTORY
```

caller or reservation authority. Those remain required external joins.
