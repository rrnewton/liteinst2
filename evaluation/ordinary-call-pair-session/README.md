# CallPair input-session qualification

This recipe requires a clean exact revision containing the reviewed application,
SDK, native adapter, reference, receipt, producer and output checker. It is a
scalar input-session qualification. Its numeric rows do not supply physical
receipt ownership, native state, timing, accuracy or broader A5 authority.

Before the campaign, a separate original-address native qualification must finish
at that same revision. Supply its root-owned prerequisite manifest and the
independently frozen root protocol, each by path and SHA256. The recipe validates
all 37 native stages, 192 pairs, 384 normal reaps, complete source/tool/artifact
pins and exact parent/child/Rust-caller geometry. A local status or closed prefix
cannot satisfy this prerequisite. The campaign never launches or retries it.

Use the source-reviewed external process owner with one hard three-CPU reservation
and a fixed 7200-second / 8-MiB log bound. The CLI is:

```
python3 -B evaluation/ordinary-call-pair-session/reproduce.py \
  --revision REVISION --reservation-tag TAG --raw FRESH_IGNORED_DIRECTORY \
  --toolchain TOOLCHAIN --user-home USER_HOME --cargo-home CARGO_HOME \
  --native-receipt MANIFEST --native-receipt-sha256 MANIFEST_SHA256 \
  --native-protocol PROTOCOL --native-protocol-sha256 PROTOCOL_SHA256
```

All paths are caller supplied. The raw directory must be absent and underneath
this checkout's `ignored`; its matching `target/evaluation` log directory must
also be absent. Inherited affinity must be exactly three CPUs. Controller, worker
and producer use the sorted first, second and third CPU respectively; original
reference calls use the worker CPU. The outer owner must independently retain
its request, hard reservation/load, normal allocator return and closure evidence.
A tag or affinity alone is not reservation proof.

The fixed plan contains 35 setup/control stages, eight malformed reference frames,
32 original parent-only references and five complete qualifications. Each
qualification runs K10 then K1000 over all 32 unchanged corpus cases: 320 installed
children, without retry or replacement. Original accepted bytes and all scalar
results must match before installed cohorts start. Each reference makes one
uninstalled parent call whose original E8 reaches the child. The C caller is
independently admitted; Rust-caller full-state proof is the separate native gate.

Controls require all 80 ordinary methods (68 prior plus 12 CallPair), 48 SDK
methods (18 prior plus all 30 CallPair), eight core methods, all 61 prior Python
methods, ten nested checker methods, six campaign methods, six separately named receipt
methods and five producer methods, four original Python methods, six unchanged mount C controls and four
parent-reference C controls. The one runner-controls stage executes all17 campaign/receipt/producer class-and-method tuples; all92 required Python methods remain represented.
The six receipt bodies and five producer bodies are inherited unchanged. Extra or missing names inside selected
namespaces refuse acceptance. The independent native gate keeps its own complete
208-plus-one-ignore / 14 / 30 / eight / 96 inventory.

The existing 2-ms arm, 10-ms period and 2-s shutdown checks, 520-epoch limit and
three resident banks are unchanged. Every installed producer has its original
15-second absolute deadline, inside 20 CPU seconds / 30 wall seconds / a
55-second outer owner. Case 30 requires actual 520 arms, history end 521 and a
sampled prefix at least 513; case 31 retains its fixed read hold and actual
blocked-write witness. All complete output remains checked and retained.

A normally reaped, fully identified functional failure stays FAILED and the next
fixed slot runs. Unknown cleanup, missing APP identity or an unjoined envelope
stops the campaign, leaving all later rows UNRUN. No printed completion can waive
an exit, source, deadline or custody failure.

Evidence uses the existing prospective 2-GiB budget, preserving the original
stream limits and a 64-MiB final-output reserve. Before each stage its complete
conservative stream/log/metadata maximum is reserved. Every retained copy is
charged; shared build products/cache and only the declared compiler `raw/tmp`
are separately preflighted build space. Evidence may not use that exclusion.
There are shared immutable DSO/application copies, not per-case binary copies.
A budget refusal is FAILED with remaining slots UNRUN, never a successful stop.

Complete raw requests, closures, streams, pins and outcomes remain ignored.
After complete owned closure and final retention checks, `outcomes.csv` contains
all 762 fixed stage/reference/malformed/installed/qualification/native/overall
rows and `summary.json` indexes them; together they are below 80,000 bytes.
An unsafe stop retains the raw failure but refuses a complete public projection.
A local functional pass still requires the external campaign owner to accept its
normal final exit and retained source/reservation/closure joins.

The public prerequisite owner and freezer are
`evaluation/ordinary-call-pair-native/launch.py` and `freeze.py`; follow

source-freeze, one-owner invocation and post-closure manifest procedure. Commit
those sources together with the native, receipt-helper and intended session
sources before selecting their one shared clean revision. Freeze using the
pinned Python executable:

```sh
"$PYTHON" -I -B evaluation/ordinary-call-pair-native/freeze.py \
  --revision "$REVISION" --toolchain "$TOOLCHAIN" \
  --cargo-home "$CARGO_HOME_DIR" --user-home "$USER_HOME_DIR" \
  --allocator-root "$ALLOCATOR_ROOT"
```

The freezer accepts optional explicit `--xdg-runtime-dir` and
`--dbus-session-bus-address` inputs as documented there. It retains a fresh
per-revision protocol and a `SOURCE_FROZEN_UNRUN` marker. The campaign and receipt
controls authenticate the tracked public launcher directly; they require no
ignored source copy. Launcher SHA256 remains
`5665c1dd0b98ff0884fd3132ed807b33e814463d226158f532ea4605ea90b7e5`.
Retain the marker's original protocol path/hash, then invoke the pinned Python
with `-B evaluation/ordinary-call-pair-native/launch.py --protocol "$PROTOCOL"
--sha256 "$PROTOCOL_SHA256"` once. That native owner retains its distinct
1200-second / 8-MiB bound. After full normal closure and source/native audit,
serialize the seven-field root manifest using the documented procedure and
retain its first hash. Supply that manifest and the original protocol to this
7200-second campaign. Freezing, wrapper exit or manifest serialization alone
cannot satisfy `accept_native`; no owner semantics, native gates, retry policy
