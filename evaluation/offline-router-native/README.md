# Offline router native validation

`final_admission.py` reconstructs saved full-program verifier results and both
bootstrap builds before preparing requests for the native observer. It retains
the exact executable copies, dependency files, build records and source profile
through child cleanup. The checker compares complete immutable pages and actual
mapping permissions; completion alone proves neither route coverage nor native
correctness.

This is an explicit unsafe launcher interface. The caller must review and accept
the exact GNU loader, constructor, signal and lifetime obligations. Sealed request
bytes do not establish those obligations. Safe admission continues to refuse.
The final profile separately pins all committed native sources, the built
observer, and reviewed whole DSO/dependency facts. Actual build and observer
integration remain required before a native qualification can pass.

Run the additive source controls with Python 3.9 or later:

```sh
python3 -B -m unittest discover -s evaluation/offline-router-native -p '*controls.py'
```

Use a reserved CPU set on a shared host. Keep raw captures and profiles under
`ignored/`; publish compact results with exact revision, command and hardware.
These controls do not execute a candidate ELF.
