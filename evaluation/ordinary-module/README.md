This recipe qualifies ordinary calls to CSV field counting and unchanged FreeBSD
bounded length in one dynamically loaded module and one shared source page.
Run `reproduce.py --revision REV --toolchain TOOLCHAIN --cargo-home CARGO_HOME
--output ignored/NEW_RUN` from that clean revision inside a one-core cpuset
reservation. Retain the reservation record alongside the private receipt.

The fixed order is K16, then K1, one attempt each and no retries. Each cohort
performs 32 original and 32 installed calls: all 16 CSV records alternating with
all eight bounded-length cases twice. It requires every declared RET of both
functions, complete journal/report/history joins and actual process closure.
K16 retains 32 samples; K1 retains two and records 30 FunctionClosed calls.

The recipe builds the application and copy controls in release mode, preserves
both source bodies, uses explicit certified-block/whole-function policies, and
records revision, commands, binary hashes, hardware, affinity and load averages.
Each child retains the 15-second cooperative deadline plus 20 CPU/30 wall-second
outer bounds. A failed prerequisite leaves later cohorts UNRUN. The output is
functional evidence; it does not qualify native state, latency or performance.
Keep raw logs/ELFs in ignored/. Publish only the small numeric results tables and
a sanitized receipt with exact revision, command and reservation/load details.

The recipe retains original hashes for its plan, exact command and closure records,
logs, cohort requests/streams/receipts/tables, sources, tools and input artifacts.
It rechecks these pins before later owned work and final acceptance; a changed
completed file cannot acquire a replacement hash. The caller disassembly must
also match the complete FUNC symbol VA and size. Parser stack arithmetic checks
necessary public bounds only; actual stack VMA and return custody remain the
consumer's responsibility. Eight fabricated Python controls exercise these joins;
they provide no native execution evidence.
