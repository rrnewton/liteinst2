# Finite compiled-function core state oracle

`cargo test --test compiled_selected_state_oracle -- --nocapture` runs sixteen
isolated cases: both complete functions × eight entry/RET masks. Each case uses
the twelve literal inputs in [oracle.py](oracle.py) and the fixed state seeds
`0x1234567887650000` and `0x1234567887650cd5`: **384 required comparisons**.
The other function has the complementary three-bit mask. Three pure controls
freeze the literal answers/reachable population, reject invalid role layouts and
require exact private-source/shared-generated RX mapping roles;
inside the two mask-zero native cases, four contradictory expectations each
must fail against an already captured baseline, without extra native attempts.
No executions or validation results are asserted by this source document.

MOV-only setup at offset `0x100` initializes 64 owned bytes and RSI; NativeOracle
supplies the exact owned-data RDI. A direct JMP enters the chosen complete
function, whose RET consumes the original oracle return word. There is no nested
CALL, and the existing application-stack/red-zone window covers the whole leaf.
The independent itinerary includes every loop iteration and the exact chosen
return. Before patching, immutable observations check inputs, bounded read
addresses, scalar result, ADC carry/count progression, data and stack preservation.
The patched run then uses the unchanged complete ordered GPR/RFLAGS/xstate,
data-page and application-stack comparator at every actual instruction visit.

Both complete plans are composed on the same private source page and published
as one bundle with complete leases. Six managed-bound identities retain exact
entry/RET event roles. Only parent-owned unique writers toggle controls; TLS
retains owners, never writers or dispatch tokens. Callbacks deliberately clobber
scratch GPRs, XMM, x87 and flags without changing HookContext or application data.
Full source/generated bytes, exact private-source/shared-generated RX VMAs and PC translations must remain exact
across every toggle and replay. Complete source and generated lifetimes are
leased through retirement. Allocation ceilings, 5–80-byte whole-function grammar,
20 CPU/30 wall-second isolation and 20,000-step/15-second oracle bounds remain
unchanged. Failure is failure; there are no retries or dropped masks/inputs.

This is finite core-bundle evidence for these exact compiler bodies and inputs.
The private fixture page additionally contains setup; it is not the actual DSO
mapping. It does not qualify the complete selected-session SDK/controller,
loader lifetime, concurrent mutation, CET, arbitrary inputs, or asynchronous
preemption. It makes no performance or strict 2 ms deadline claim. The existing
372 generic ADC and 372 whole ADC comparisons are unchanged, separate populations.
