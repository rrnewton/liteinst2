# Producer-recorded frame metadata

The optional `TrampolinePlan::emit_with_frame_trace_at` API returns the ordinary
trampoline image and a separately fallible frame ledger. Ordinary `emit_at`
continues without collecting metadata. A metadata refusal preserves successful
code emission; ordinary emission errors retain their existing meaning. The
image type, planner contracts, publication and global PC registry are unchanged.

The producer records exact instruction extents, save/restore transitions,
original-head identities and instrumentation CALL/return PCs as it emits code.
Encoder offsets resolve producer labels; coalesced helper byte slices must
match at their final positions. Original relocated instructions are identified
without inventing their frame effects. Unknown expansion or byte ownership
refuses metadata. The application stack and controller-owned stack are distinct
origins; the latter currently has an explicit metadata refusal.

The ledger describes temporary instrumentation storage, including the normal
original-RSP relation through the R12 context anchor. These relations are not
the original function's CFA. Exact original-CFI validity at each new hook head,
a qualified frame-preserving callback, consumer/FDE construction, registration
and lifetime ownership remain separate requirements. The ledger registers
nothing, authorizes no unwind or exception propagation, and clears no native
or asynchronous-unwind qualification. It retains an image clone, including
controller ownership for controlled images, but does not establish published
code/CFI lifetime. Output limits bound accepted records rather than all
intermediate assembler work.

Private validation on the AMD EPYC Zen 5 dev host passed the nine new model
tests. Their fixed inventory includes 14 accepted metadata products, 13 helper
groups under two distinct GPR/flags seeds (26 modeled call completions), six
required refusal inputs, one matching ordinary-emission error pair and six
invalid metadata/model/binding checks. The refusal inputs cover replacement,
controller-stack and exact-syscall contracts, expanded relocation, and the two
output limits. Every accepted final instruction extent is independently decoded;
the model checks saved GPR/flags recovery at each helper boundary. Extended-state
memory is opaque in this model, so this is not a native xstate or unwind proof.
The full private library run passed 169 tests, failed zero and retained one
existing ignore; the nine new tests are included in that total.

Fresh legacy parity also passed all 72 fixed B1/B2/T1/T2/T3/upstream leaf and
engine rows: 45 required successes, 27 exact refusals and 59 images per library.
All 334 corresponding captures per side are byte-identical, including original
source, complete contracts, edits, PC maps, generated bytes and candidate/search
evidence. The unchanged comparator passed one positive and eleven negative
calibrations. Both libraries used the same actual observer pointer without
normalization; observer calls and generated-code execution were zero. This
finite result is planner/emitter compatibility evidence, not native execution
of the emitted images.
