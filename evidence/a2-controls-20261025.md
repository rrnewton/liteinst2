# A2 independent coalesced controls — 2026-10-25

This partial A2 milestone adds independently enabled observing callbacks in a
shared relocation image on an AMD EPYC Zen 5 dev host. Mutable control state is
separate from immutable generated code, including physically grouped aliases.
[`COALESCED-CONTROLS.md`](../COALESCED-CONTROLS.md) describes the API and lifetime
contract. A2 remains open for classified search termination and the recorded
generated/sampled campaign. Raw logs, snapshots, hashes and reviews remain in
ignored/.

The planner requires distinct controls at increasing original heads inside one
certified basic block. Existing source, entry, saved-resume, byte-lock, allocation
and transaction rules apply. Each original instruction executes in every enable
state. The lower-level emitter separately supports internal direct branches;
its CFG fixture does not relax the planner's basic-block prerequisite. Replacement
semantics and shared-arena control publication are explicit refusals.

The dispatcher reads one atomic Boolean after saving full supported application
state. Disabled callbacks still pay that save/dispatch/restore cost. A release
store is a request, with no callback-drain or completed-epoch claim. Executable
allocators retain control identities as long as the existing process-lifetime
code; unused plans/images release ordinary references, and unpublished rollback
unmaps before releasing controls. Fork inherits independent snapshots. The
fork-shared arena refuses controls before reserving a slot, while static arena
allocation remains a required positive.

## Native contract and lifetime

Seven bounded child scenarios complete five controlled bundle cycles containing
seven images, with 1,148 native calls and 822 callbacks. A separate unexecuted B2
transaction sets up an ownership conflict. Single-image cases exercise all eight
three-control masks; grouped cases exercise all 64 six-control masks on the same
two published images. Every body has four original entry heads. Tests check
arithmetic results, exact ordered callback identities and logical PCs, and every
callback counter. Every setter immediately checks all other control states.

The grouped fixture requires two virtual pages/8,192 bytes and one backing
page/4,096 bytes at disjoint offsets. Source and complete executable allocation
bytes remain unchanged across masks. Native lifetime checks drop caller controls,
plans and images before executing all installed heads; emitter checks also drop
the executable handle and verify that the code retains the final control owners.

Fourteen planning refusals are required. Both grouped-alias collision orders and
one matching-snapshot byte-ownership conflict require BeforeWrite with unchanged
source; successful retry/replanning then executes the complete positive cohort.
Publication and retirement finalization failures each require KeepGated, retained
code/maps and a poisoned lease; both retries require LeasePoisoned/BeforeWrite.
No execution is attempted behind a poisoned gate. Weak-reference unit checks
separately establish unpublished private/grouped control release and active-code
retention; the poison fixture itself does not measure payload reference counts.

## Independent architectural oracle

The existing native single-step comparator, state masks, six negative
calibrations, 15-second trace bound and 20,000-step limit are unchanged. The fixed
cohort uses two seeds and every declared original head:

| Fixture | Original heads | Enable masks | Direct emitter comparisons | Installed comparisons | Retired comparisons |
|---|---:|---:|---:|---:|---:|
| Bounded forward/backward CFG | 6 | 8 | 96 | 0 | 0 |
| One published coalesced image | 4 | 8 | 0 | 72 | 8 |
| Two physically grouped images | 8 | 64 | 0 | 1,040 | 16 |
| Total | | | 96 | 1,112 | 24 |

The CFG contains a forward jump that skips an action and a bounded backedge
through memory arithmetic and a comparison. Handwritten visit streams require
exactly 280 ordered hook events across its 96 comparisons. Published-image totals
include an additional all-enabled phase after dropping every external control
and pure-plan owner: eight single-image comparisons and sixteen grouped
comparisons. Retired executions compare restored original behavior.

Grouped qualification publishes once in a single-thread child, then forks two
fixed workers covering 32 masks each. The workers inherit the same source and
images and independent control snapshots; they neither republish nor re-emit.
The parent checks both exact comparison/event receipts and complete 64-mask
coverage, then executes the owner-drop and retirement phases. Kernel checks
require shared RX aliases, the same backing inode/offset, seals and rejected
write upgrades. Each individual control store is bracketed by source and full
generated-page byte checks, in addition to the existing batch/trace checks.

Before the first oracle execution, compilation exposed an incorrectly chosen
fixture observable: `routed_entries()` counts handled runtime entries rather
than configured routes. The fixture now verifies every configured original head
and exact generated route in the plan, requires the SIGILL-router obligation,
and checks the parent's handled counter remains zero across forked tracees.
All alternate-entry executions remain required. Review also strengthened
per-store independence and byte-invariance checks; it removed no comparison.

## Static compatibility and validation scope

A frozen before/after harness compares 28 pre-existing static emitter fixtures,
33 callback operands and 10,112 emitted bytes, together with every PC map and
layout field. The only normalized bytes are the eight-byte callback-address
immediates independently decoded at declared MOV/CALL sites; process address
randomization changes those operands. Every other byte and all maps/metadata
match exactly. The old capture and harness hashes were frozen before controls
activation. An initial harness-construction error used a window shorter than
five bytes; it was repaired before freezing either comparison, without changing
production or dropping the fixture. Its failed log remains private.

The command runner adds two focused controls gates. Its workspace-command
backstop was prospectively widened from 180 to 360 seconds before controls
qualification: the preceding workspace measured 139.28 seconds, and the new
oracle has a separately bounded 170-second wrapper. Every focused command
retains its 180-second cap. The new grouped workers retain their declared
150-second bound; trace budgets and coverage denominators remain unchanged.
This aggregate-work allowance is not a performance result or a timeout pass.

Coverage remains finite Linux/x86-64 AMD evidence under the existing no-CET and
caller-certified entry/quiescence envelope. There is no concurrent visibility,
drainage, asynchronous signal/unwind, Intel or shared-control-across-fork claim.
Runtime control timing and completed-toggle contracts remain A4 work.
