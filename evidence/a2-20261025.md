T1 has a separate version-3 `PrefixedPun` contract. It uses P redundant `0x2e`

actual byte/word/dword store and unchanged padding are authenticated. Generalized
puns remain first in the install-once search, followed by ordinary relocation
and then T1. RapidProbe's separate exact-byte toggle contract is unchanged.

Immutable grouping keeps every image at its encoded virtual address. Disjoint
page offsets share a sealed backing page; overlapping offsets and multi-page
images receive explicit separate backing. Overlapping virtual mapping extents
refuse. All four file seals precede RX shared aliases, descriptors close after
staging, and rollback releases every staged alias. Only an image's own virtual
alias publishes its PC maps. Mutable probe state is excluded.

measurements, not interchangeable savings claims or workload performance data.
Strict checks cover seals, rejected write transitions, exact shared inode/offset,
closed descriptors, distinct native results, PC-map isolation and collision
